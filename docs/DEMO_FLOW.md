# 5-minute judge demo

1. Register a new citizen. The API sends the user to the 5-round Civic Decision Challenge.
2. Finish the five rounds and land on Citizen Dashboard with a Civic Mind Score.
3. Click Report. Submit a water contamination complaint with a phone, 600045 / Tambaram / Selaiyur and one image.
4. Show the result page: AI summary, confidence, priority, Civic Issue and automatic route.
5. Open the Officer portal using `OFF-WAT-001` / `Demo@12345`. Show the assigned case in the priority queue.
6. Move it through Under Investigation → Action Started → Resolution Submitted.
7. Return to citizen case page and verify. Show the badge changing to Bronze and the citizen notification.
8. Open Admin portal `ADM-001` / `Admin@12345`. Show the same case plus global analytics and the AI review queue.

Do not describe demo seed records as real government data. The geography in the seed is explicitly demo data.
